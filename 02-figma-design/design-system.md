# Docklands Creative – Design System

## 1. Purpose

This document defines the visual design system used for the Docklands Creative website redesign.

The design system ensures consistency between the approved Figma designs and the later WordPress/development implementation.

---

## 2. Visual Direction

The visual identity combines:

- Dark, high-contrast sections
- Clean white content areas
- Bright accent colours
- Strong modern typography
- Rounded UI cards
- Clear calls to action
- Generous spacing
- Minimal but expressive layouts

The overall direction is intended to communicate creativity, digital capability and professional confidence.

---

---

## 4. Typography

The typography follows a modern sans-serif approach.

### Headings

Large, bold headings are used to create strong visual hierarchy.

Examples:

- We design. We build.
- Digital solutions tailored to your business goals
- Projects that make an impact
- Ready to grow your business?

### Body Text

Body text uses a smaller regular weight and focuses on readability.

### Navigation

Navigation text remains compact and clean to avoid visual clutter.

---

## 5. Buttons

### Primary CTA

Primary buttons use:

- Orange background
- White text
- Rounded corners
- Compact padding
- Strong visual contrast

Examples:

- Start a Project
- Book a Consultation
- Book a Consultation →

### Secondary CTA

Secondary actions use a more subtle treatment and are visually subordinate to the primary CTA.

---

## 6. Cards

Cards are used throughout the website for:

- Services
- Projects
- Process stages
- Insights/articles

Card characteristics:

- Rounded corners
- Clear internal spacing
- Strong hierarchy
- Short supporting text
- Consistent alignment

Project cards use darker backgrounds when placed inside dark sections.

---

## 7. Navigation

The main navigation contains:

- Services
- Work
- About
- Insights
- Contact

A prominent consultation CTA is positioned on the right side of the desktop navigation.

The mobile layout uses a compact navigation/menu treatment.

---

## 8. Layout

The website uses a structured central content container.

The layout follows:

- Consistent horizontal margins
- Clear section boundaries
- Strong vertical rhythm
- Responsive column layouts
- Large hero areas
- Full-width background sections

---

## 9. Section Styling

The landing page alternates between dark and light sections.

### Dark Sections

Used for:

- Hero
- Projects
- Testimonial
- Final CTA
- Footer

### Light Sections

Used for:

- Services
- Value proposition
- Process
- Insights

This contrast creates visual rhythm and separates major content groups.

---

## 10. Responsive Design

The design is intended to work across:

- Desktop
- Tablet
- Mobile

### Desktop

Uses multi-column layouts and larger typography.

### Tablet

Content columns reduce while maintaining visual hierarchy.

### Mobile

Layouts stack vertically.

Navigation becomes compact.

Cards become single-column or horizontally scrollable where appropriate.

Typography scales down while maintaining clear hierarchy.

---

## 11. Visual Components

Core reusable components include:

- Navigation bar
- CTA buttons
- Service cards
- Project cards
- Process cards
- Insight cards
- Testimonial block
- Footer
- Section headings
- Accent labels

---

## 12. Design-to-Development Principle

The Figma design acts as the visual source of truth for development.

The WordPress implementation should reproduce:

- Layout structure
- Typography hierarchy
- Colour relationships
- Component styling
- Spacing
- Responsive behaviour
- CTA placement

Any implementation changes should preserve the overall visual language of the approved Figma design.

---

## 13. Future Refinement

The design system may be refined during the final implementation stage.

Potential refinements include:

- Exact colour values
- Font selection
- Responsive breakpoints
- Animation behaviour
- Hover states
- Accessibility improvements
- Component optimisation
