1. Navigation
2. Hero
3. Trusted brands
4. Services
5. Projects
6. Value proposition
7. Process
8. Testimonial
9. Insights

## 4. Visual Review

The following visual characteristics are carried forward into development:

- Dark navy/near-black brand sections
- White information sections
- Orange primary CTA
- Pink/magenta accent elements
- Strong modern typography
- Rounded cards
- High-contrast layouts
- Generous spacing
- Clear section hierarchy
- Consistent visual components

---

## 5. UX Review

The design has been reviewed against the following UX principles:

### Clarity

The agency proposition is communicated immediately through the hero.

### Navigation

Primary website destinations remain visible and easy to understand.

### Discoverability

Services and project work are introduced prominently.

### Trust

Projects, testimonials and client/brand evidence support credibility.

### Conversion

Calls to action appear at key points throughout the journey.

### Readability

Content is divided into short sections and scannable blocks.

### Consistency

Repeated components use consistent visual styling.

## 9. Development Acceptance Criteria

The WordPress implementation should be reviewed against the Figma design
using the following criteria:

- Layout matches the intended structure
- Typography hierarchy is maintained
- Colours are consistent
- Buttons match the design system
- Cards maintain consistent styling
- Images maintain intended proportions
- Navigation works correctly
- CTAs are functional
- Responsive layouts work correctly
- No horizontal overflow occurs
- Mobile content remains readable
- Footer structure is maintained

---

## 10. Figma-to-WordPress Rule

Figma is the primary visual reference during initial implementation.

Development should reproduce the approved design as closely as practical.

Where technical or responsive constraints require a change, the priority
order is:

1. Usability
2. Accessibility
3. Responsive behaviour
4. Performance
5. Visual fidelity
