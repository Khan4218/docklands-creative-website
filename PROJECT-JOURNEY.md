# Docklands Creative — Website Redesign Project

## Project Overview

This repository documents the complete development journey of the Docklands Creative
website redesign, from research and competitor benchmarking through Figma design,
WordPress development, testing and final implementation.

## Project Workflow

Research
↓
Competitor Benchmarking
↓
UX & Website Requirements
↓
Figma Design
↓
WordPress Development
↓
Responsive Testing
↓
Final Website

---

# 01 — Research

The project began with research into digital agency websites and the competitive
landscape.

The research focused on:

- Website structure
- User experience
- Visual hierarchy
- Digital capability
- Service presentation
- Portfolio presentation
- Calls to action
- Mobile responsiveness
- Brand positioning

## Competitor Benchmarking

Five competitor websites were reviewed and benchmarked.

The benchmarking process was used to identify:

- Competitor strengths
- Competitor weaknesses
- Common industry patterns
- Opportunities for differentiation
- Digital and innovation capabilities
- Premium positioning opportunities

The results were consolidated into a Master Competitor Benchmark.

---

# 02 — Figma Design

The website was then translated into a visual interface concept in Figma.

The current design direction uses:

- Dark navy primary sections
- Magenta/pink accent colour
- Starry/dotted visual background
- Compact navigation
- Strong typographic hierarchy
- Technology-focused hero visual
- Trust/brand strip
- Service cards
- Featured projects
- Client/value proposition section
- Process section
- Client testimonial
- Insights/news section
- Strong conversion CTA
- Footer navigation

The design was developed for both desktop and mobile presentation.

Figma was used as the visual source of truth before implementation.

---

# 03 — WordPress Development

The approved Figma design will be developed as a custom WordPress theme.

The development approach is based on:

- Semantic HTML
- CSS
- JavaScript where required
- PHP/WordPress template files
- Responsive design
- Reusable components
- WordPress content management

The WordPress site is being developed locally using Local.

---

# 04 — Development & Testing

Development will include:

- Theme implementation
- Component development
- Responsive layouts
- Navigation testing
- Button and link testing
- Mobile testing
- Desktop testing
- Visual comparison against Figma
- Performance and usability checks

GitHub will be used to maintain version history throughout development.

# Development Philosophy

The project follows a design-to-development workflow:

Figma
→ WordPress
→ GitHub
→ Testing
→ Final implementation

The objective is to create a professional digital agency website that combines
strong visual design, clear communication, responsive UX and maintainable
WordPress development.
